## 内容与显示

- 新增／完善 110 组项目原创易错辨析，如 affect/effect、advice/advise、quiet/quite。中文说明以 CC0 提供，使用现有词库义项，未宣称来自学习者错误率统计。
- 现有 24,043 条形近对照恢复显示，覆盖 11,994 个词。此前安卓 UI 过滤了“形近对照”内容，本次分为独立“形近词”栏目；易错词与形近词分别显示各自音标和释义。另补 4 条缺少的明确拼写对照。部分旧形近关系升级为带解释的易错辨析，因此形近条目总数与旧版不直接相加。
- 现有易错词相关内容覆盖 1,633 个词，共 1,828 条。并非每个单词都有可靠易错关系，不为补齐数量生成任意相近词。
- 新增 734 个主词英式音标，英式覆盖 27,067 / 28,167 词；另补关联词美式 254 项、英式 570 项，共补 1,558 个音标字段。
- 末尾的 `ɚ` 和 `ɝ` 是有效 IPA 记号。本次安卓显示为常见的 `ər` 和 `ɜːr`，同时保留 `ɹ→r`、`ɫ→l`。原始词库读音不改写，不删除 r 音。
- 修正关联词在主词条音标为空时不能使用补充表的问题。首选口音缺失时，可显示另一口音并明确注明缺失口音。

## 公开来源与边界

音标来自 [Wiktionary / Kaikki](https://kaikki.org/dictionary/English/) 的精确词条，以及已有 [ipa-dict 美式数据](https://github.com/open-dict-data/ipa-dict)。只采纳明确的 US/UK/RP 标签；无口音标签的读音必须与相应口音的 [WikiPron](https://github.com/CUNY-CL/wikipron) 音素序列一致。保留原词条、词性、口音、URL、下载校验值和 CC BY-SA 4.0 许可；不预测发音、不将美式机械转换为英式。

已查询 2,534 个缺口词条，公开页面存在未收录、无适用口音及网络获取失败的情况。主词仍有 1,100 个英式栏未能核实；关联词仍有 4,828 个美式栏、3,566 个英式栏为空。已有非空读音保持原值。关联词包括派生形式和多词表达，不把单词读音拼接冒充整词读音。

逐项归属见 `app/src/main/assets/public_pronunciations_v15.json`；检索快照、筛选及复现脚本位于 `tools/data/public_ipa_v15/`、`tools/fetch_public_pronunciations_v15.py` 和 `tools/complete_confusables_v15.py`。
