# 2.0.10 阶段进度与验证记录

仅维护安卓。已删除项目 ios/ 的 48 个文件及对应临时构建输出及基线快照；未卸载 iPhone 上既有应用，未删除系统 Apple 开发账户或证书。

## 本轮词库变更

保留全部 28,167 个单词 ID、顺序、词频排名和既有难度；不修改学习记录。新增 7,765 个原缺例句词的双语例句，处理 8,781 条缺中文项，修正 551 个词的释义或词性，新增 97 条搭配、696 条派生词关联、830 条同义关联和 15 项词形。新增四个明确来源的主词条英式读音，以及66项关联读音补充。

1—8级词均已有至少一个例句；1—5级既有例句的中文空缺也已清零。**全库仍有 4,698 个词缺例句、3,029 条既有例句缺中文，尚未全库补齐。** `dist/validation-v2.0.10/remaining-content.json` 列出剩余项，防止把分批结果误认为全部完成。无适用派生词或同义词的词不强制凑关系，缺乏明确口音依据的音标不靠美式改写成英式。

公开来源优先采用许可明确的中文维基词典和 Open Dictionary v2.0；后者包含模型扩写内容，其来源与生成性质保留在词条和许可资产中。项目原创例句、译文与释义改正按 CC0 记录。缺中文且有匹配公开双语语境的旧例句用完整双语对替换，不拼接无关译文；移除的原句和原因保留在 `removed-examples.json`。原始来源、逐分片哈希及报告位于配套 tools 文件和 dictionary_sources.json。
