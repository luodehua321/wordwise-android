# 商店素材目录

- `应用商店文案.md`：应用名称、slogan、短描述、长描述、关键词与 A/B 短句。
- `privacy-policy.md`：离线应用的隐私政策模板（上传前替换开发者信息并托管）。
- `screenshots/raw/`：模拟器原始截图（1080 × 2400）。
- `screenshots/marketing/`：带标题与手机外框的商店展示图（1080 × 1920）。
- `icon-512.png`：商店用 512 × 512 全出血方形图标（商店自行裁圆角）。
- `feature-graphic.png`：可选 1024 × 500 横幅。
- `screenshots/contact-sheet.png`：六张展示图的联系表，方便快速预览。

## 商店截图建议顺序

1. 无限流背单词（学习卡正面）
2. 先判断，再揭晓（答题后释义 + 例句）
3. 难词自动进易错本（易错本）
4. 你的水平会自己长出来（我的 / 水平环）
5. 一个词，一整个语境（单词详情）
6. 2.8 万词，全在本地（隐私 / 数据说明）

## 规格

- 原始截图：1080 × 2400（Android 手机，含状态栏）。
- 展示图：1080 × 1920（适合大多数国内 Android 商店；如商店要求 9:16，可直接使用）。
- 图标：512 × 512 PNG。
- 文案语言：简体中文；英文 slogan 备用。
